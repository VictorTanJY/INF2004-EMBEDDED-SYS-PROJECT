CONNECT YOUR ROBOT

One window. All the readings.

The robot's MQTT broker runs on this laptop. Use the local launcher for live readings and controls.

01

Extract and start

Needs Python 3 and Mosquitto. Double-click Start-Dashboard.cmd and leave its window open. It opens http://127.0.0.1:8765.

02

Same hotspot

Laptop and Pico on the same 2.4 GHz hotspot. The firmware's MQTT_BROKER_IP must be this laptop's Wi-Fi IPv4 address.

Default: the broker on this laptop, TCP port 1883.

Reset the fault?

Keep the robot level and the wheels clear. Reset clears the fault and re-runs the start-up checks; calibrate again before the next run.

Start a run?

The robot will drive off along the line.
